# Security and contamination controls
The provider adapter sends only the approved public root and path-bounded candidate URLs to Firecrawl. It has page, byte and timeout limits, rejects ambiguous paths and mismatched source/final URL metadata, and never executes, forwards to an LLM, or interprets page text as commands. Use only an operator-controlled dedicated public origin with tested robots/access and redirect behavior. The adapter does not prove upstream fetch-time DNS restrictions, and matching metadata is not an auditable redirect trace. Keep execution off until those assumptions are tested. Saturated maps fail rather than pretending to prove uniqueness.

Start B with protocol, run ID, root and minimum service permissions only. No host credentials, Agent A workspace/memory, shared cache, exact beacon path, or unvalidated external links. Do not store a credential's value in source, command lines, evidence or logs. Signatures must use a previously pinned public key or independent timestamp receipt, not a key discovered beside the bytes as its only trust anchor. Archive a manifest hash outside the bundle; a co-located manifest alone can be rewritten. Avoid changes between T0 and T1; record intentional or accidental deviations in the contamination log, including no intervention if independently supported.
