# Architecture
A writes canonical beacon JSON and detached hash; the fixture publishes the inert HTML envelope to a local rendezvous directory with a random filename. B starts in a separate process with minimal environment variables and no exact beacon path. It records discovery and packages the nonce, original hash and synthetic post-start pulse. The verifier re-parses the rendezvous, checks chronology and compares the response to independently supplied inputs, then checks bundle byte hashes.
The Firecrawl adapter uses bounded Map then Scrape. The adapter contract and the actual connector probes are distinct. The public origin, publication receipts, provider signature checks, hosted scheduler and real B publisher are separate unimplemented or unvalidated integration gates.
