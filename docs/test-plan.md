# Test plan
Use unittest and preserve first failing tests and final passing output. Coverage includes nonce generation, strict JSON, scope, stale/wrong ID, malformed/ambiguous candidates, capped map, unexpected destination, tampered beacon/response, wrong challenge, stale/future or mismatched freshness, and fixture subprocess/evidence integrity. RED logs here show missing modules before implementation, not individual proof of a behavioral RED for every case.
External gates: real provider retrieval of a TBP dry-run beacon, external pulse signature and independent retrieval, response publication, short external scheduled run with no manual trigger, frozen revision, replay/duplicate rejection, and signer/timestamp checks. A successful provider health probe is not an external handshake.
